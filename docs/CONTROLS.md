# Controls (prototype)

- WASD: move
- Mouse: look around (click the game to capture the mouse)
- Space: jump on foot / climb in flight
- Shift: run
- F or on-screen **САМОЛЁТ**: toggle flight
- Ctrl/C: descend in flight
- Esc: pause
- Android: swipe on the right side to look; use on-screen jump and flight buttons. Full left-side virtual joystick is planned but not yet implemented.
